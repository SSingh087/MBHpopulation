Summary of Improvements

I refactored `eval_p0.py` and improved the logic that computes the initial semi-latus rectum (p0) for EMRI inspirals using the Pn5AAK waveform.

Key changes and rationale

1) Replace nested try/except with a progressive-bounds loop
- Old: multiple nested try/except blocks made flow hard to follow and difficult to extend.
- New: a single loop tries progressively wider bound ranges: near-separatrix → mid-range → far-range. This is clearer and easier to maintain.

2) Replace magic numbers with named constants and physical motivations
- MIN_SEPARATION_FROM_SEPARATRIX = 0.5  # small offset to avoid numerical instability near separatrix
- MAX_ADAPTIVE_OFFSET = 20.0             # conservative large offset for extreme fallback cases
Using named constants clarifies intent and makes tuning easier.

3) Mass-ratio-adaptive fallbacks instead of a single mysterious branch
- Instead of a single conditional on `log10(mu/M)`, the fallback uses three physical regimes:
	- Small mu (very small mass ratio): -9 ≤ log10(mu/M) < -6 → modest offset (MIN_SEPARATION_FROM_SEPARATRIX)
	- Medium mu: -6 ≤ log10(mu/M) < -4 → intermediate offset (2.0)
	- Large mu (less extreme ratio): otherwise → conservative large offset (MAX_ADAPTIVE_OFFSET)
This choice is more physically motivated: smaller secondaries plunge more slowly and therefore need smaller separation offsets.

4) Better logging
- Each successful solve prints a concise SUCCESS message including event index, p0, separatrix (ps), and log10(mu/M).
- Fallbacks print the reason and relevant parameters (e0, a, Y0) so failure cases are diagnosable.

5) Remove duplicated code between T > T_obs and T < T_obs functions
- Both functions now use the same solve-then-fallback strategy (the only difference is the injection time used).

Bound sequence used
- (ps + MIN_SEPARATION_FROM_SEPARATRIX, 20.)  # near-separatrix, small-to-moderate p0
- (20., 50.)                                   # mid-range
- (50., 100.)                                  # far-range / large p0

Priors review and comments
- --log10_M 5 10 → M ∈ [1e5, 1e10] M_sun. This covers a broad SMBH mass range and thus a wide range of mass ratios when mu is fixed/varied.
- --a 0.1 0.9 → reasonable spin coverage excluding exactly zero and extremal spin; good for waveform variability.
- --e0 0.1 0.7 → samples low-to-moderate eccentricities; captures non-circular dynamics while avoiding highly eccentric regimes that may be numerically unstable.
- --Y0 0.3 0.99 → samples a wide inclination range (excluding exact polar configurations), good for capturing orientation effects.
- --dist 1 8 → distances in Gpc; suitable for LISA-typical extragalactic sources.

Why this logic is an improvement
- It is easier to read, reason about, and maintain.
- The mass-ratio-adaptive fallback is physically motivated and reduces arbitrary tuning.
- Clearer logging helps diagnose problematic events so future data curation or prior adjustments are straightforward.

Next suggestions (low-risk follow-ups)
- Make `mu` a parameter (currently hard-coded to 10) or read it from `theta_ex_p0` to support variable secondaries.
- Expose the named constants (MIN_SEPARATION_FROM_SEPARATRIX, MAX_ADAPTIVE_OFFSET) as CLI arguments or config entries for easy experimentation.
- Add a brief unit test or small script that runs the p0 solver on a few representative parameter sets (one per mass-ratio regime) to validate behavior automatically.
